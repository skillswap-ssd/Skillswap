# SkillSwap

Phase 0 foundation for a peer-to-peer skill exchange product.

## Stack

- Next.js App Router
- TypeScript
- Tailwind-style utility classes backed by centralized CSS design tokens
- Mock data and extensible TypeScript models
- Vercel build readiness
- Cloudflare Workers/OpenNext script and configuration foundation

## Commands

```bash
npm install
npm run dev
npm run typecheck
npm run lint
npm run build
```
